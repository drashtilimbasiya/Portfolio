04 / PROJECT TWO

Web System PHP · MySQL

Smart Parking — Management System

A web-based parking management system developed with PHP, MySQL, HTML, CSS and JavaScript. The system allows an admin to manage parking slots, create and track bookings, handle QR-based payments, and view occupancy and revenue reports. 05 / PROJECT THREE

Android App Kotlin · Firebase

Patel Auto Garage — Service & Billing App

An Android application for managing a garage's customer service records, billing, expenses, and financial reports. Built with Kotlin and Firebase, the app enables the garage owner to create detailed bills with labour charges, GST, discounts and parts costs, track payments, generate PDF receipts, and share bills via WhatsApp. Profit and loss reports are available on weekly, monthly and two-month periods.

Detailed bill creation with all charge fields
Customer and vehicle information management
Payment tracking with pending and received amounts
PDF bill generation and WhatsApp sharing
Expenses and stolen items tracking
Profit & Loss reports (weekly / monthly / 2-month)
Kotlin XML Layouts Firebase Auth Cloud Firestore PDF Generation Android Studio
