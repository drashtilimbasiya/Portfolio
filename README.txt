# Drashti Limbasiya — Portfolio Website

A responsive, single-page portfolio made with HTML, CSS and JavaScript. It is suitable for free static hosting with GitHub Pages.

## Files
- `index.html` — portfolio content and sections
- `style.css` — design and responsive layout
- `script.js` — mobile navigation and current year
- `DRASHTI LIMBASIYA.pdf` — resume copy (if included)

## Preview locally
1. Extract this ZIP.
2. Open `index.html` in Chrome, or open the folder in VS Code and use Live Server.

## Publish free on GitHub Pages
1. Sign in or create an account at https://github.com/
2. Create a **public** repository named exactly `YOUR-USERNAME.github.io` (replace with your GitHub username).
3. Upload `index.html`, `style.css`, `script.js`, and the resume PDF if included to the repository root.
4. Open repository **Settings → Pages**.
5. Under build/deployment, select **Deploy from a branch**; choose `main` and `/(root)`, then Save.
6. Wait for the deployment to finish. The website URL will be `https://YOUR-USERNAME.github.io/`.
